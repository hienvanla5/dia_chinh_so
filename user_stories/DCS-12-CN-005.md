## 2. Mô Tả User Story
> **Là một**: Quản trị viên Hệ thống,  
> **Tôi muốn**: cấp phát khóa truy cập (API Key / Client ID & Secret) có thời hạn và phân quyền phạm vi truy xuất (Scope) cho từng đối tác ngân hàng, tổ chức công chứng,  
> **Để**: kiểm soát an ninh.

- **Giá trị nghiệp vụ**: Quản lý tập trung các kết nối đối tác, thu hồi quyền tức thì khi đối tác có dấu hiệu vi phạm điều khoản sử dụng dữ liệu.
- **Mô tả chi tiết giải pháp**: Bảng điều khiển quản lý đối tác (Developer Portal): tạo ứng dụng, cấp phát token JWT có thời hạn, cấu hình dải IP tĩnh cho phép và quy định phạm vi dữ liệu được phép gọi.
- **Điều kiện tiên quyết (Precondition)**: Đối tác đã hoàn tất thủ tục đăng ký kết nối và được phê duyệt hợp đồng dịch vụ.
- **Kết quả mong đợi sau hoàn thành (Postcondition)**: Khóa truy cập API được kích hoạt và sẵn sàng cho việc tích hợp hệ thống.

## 5. Quy Tắc Nghiệp Vụ Ràng Buộc (Business Rules)
### [QTD-34] Kiểm soát hạn mức gọi API liên ngành và đăng ký IP tĩnh
- **Mô tả**: Các tổ chức tín dụng, ngân hàng và đơn vị hành nghề công chứng kết nối API vào hệ thống phải tuân thủ hạn mức truy vấn và đăng ký IP tĩnh bảo mật.
- **Vai trò áp dụng**: Quản trị viên Hệ thống, Công chứng viên & Ngân hàng
- **Đối tượng dữ liệu**: `Khóa truy cập API Gateway`
- **Điều kiện (Condition)**: Bên thứ ba gửi yêu cầu truy vấn dữ liệu qua API Gateway.
- **Kết quả khi thỏa (Then)**: Địa chỉ IP nằm trong danh sách trắng (Whitelist) và tần suất gọi trong hạn mức cho phép thì trả lời kết quả trong 200ms.
- **Xử lý vi phạm (Else)**: Từ chối yêu cầu (HTTP 429 Too Many Requests hoặc HTTP 403 Forbidden) và ghi log nghi vấn tấn công nếu vượt ngưỡng.
